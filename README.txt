DEPLOY:
1. Create a free GitHub account at https://github.com
2. Create a new PUBLIC repository, e.g. soft-mack-website.
3. Upload all files and the assets folder, preserving the folder structure.
4. Create a free Cloudflare account at https://dash.cloudflare.com
5. Workers & Pages -> Create -> Pages -> Connect to Git.
6. Connect GitHub and select the repository.
7. For a plain HTML site, use the default/static deployment settings and deploy.
8. Cloudflare will provide a free *.pages.dev URL.

- Replace or review legal policies with an attorney before relying on them.
- Add your actual business mailing address if your legal/payment requirements require it.
- Do not claim certifications, offices, clients, guarantees, or services you do not actually provide.
